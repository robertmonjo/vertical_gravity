# outputs/bc_nbar1 — Band-consistent model fits (McGaugh–Imig)

Model fits for the McGaugh–Imig (nbar1) reconstruction under the
band-consistent (BC) protocol: each model receives the MC-100 band draw j as
the baryonic radial input v_N[j](R), paired with the Poisson phi_N[j](R,z)
calibrated to the same draw by step1.

Generated by:
  python scripts/step2_bc.py --full --no-stvg \
      --baryonic-dir outputs/nbar1 \
      --outdir outputs/bc_nbar1

Input baryonic draws: outputs/nbar1/mc100_baryonic_{radial,vertical}.csv
(unconstrained ensemble — NOT the files inside this directory).

WARNING — same filenames, different content:
outputs/nbar1/ and outputs/bc_nbar1/ both contain files named
mc100_baryonic_radial.csv and mc100_baryonic_vertical.csv, but they are
different ensembles. Using bc_nbar1/ files as input for a re-run gives wrong results.

Manuscript pipeline:
- step3_bc_fig2.py copies these CSVs to outputs/bc_fig2_nbar1/ and computes
  mc100_chi2_all_models.csv from the chi2 values in the last row of each model
  CSV. That is the file used by the paper.
- mc100_chi2_all_models_bc.csv (step2_bc internal summary) is NOT used by the
  paper and has been removed to avoid confusion.

See also: outputs/nbar1/ — the baryonic input draws.
